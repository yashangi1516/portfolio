## 🎯 Project Objective

The main objective of this project is to convert a wireframe concept into a fully functional static website using HTML and CSS.

The project focuses on:
- Creating a semantic HTML structure.
- Designing an attractive user interface.
- Implementing responsive layouts.
- Using CSS Flexbox and Grid.
- Practising clean and organized coding.
- Testing the website on different screen sizes.

## 🚀 How to Run the Project

Follow these steps to run the portfolio locally:

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Make sure the profile photograph is inside the `images` folder.
4. Open `index.html`.
5. Right-click and select **Open with Live Server**.
6. The website will open in your default browser.

### Run Without Live Server

You can also double-click `index.html` to open it directly in your browser.
